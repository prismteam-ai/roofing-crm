# Data coverage, evidence and rights

Release-bound counts, snapshot IDs, digests and observation dates come from the admitted Oracle manifest, health, coverage and source reports in the accompanying review return. Historical counts must not be relabeled as a new source refresh. The CRM does not widen a lawful source boundary to obtain a positive demo.

Public artifacts contain approved public-safe county parcel/address facts only. Provider observations and minimized official evidence are protected authenticated projections; raw source/provider intake remains private. No bulk provider export, raw owner/contact intake or unrestricted source download is exposed through the CRM.

- Native permit status is retained. `ISSUED` alone does not establish current OPEN status.
- Open duration requires an explicit active status and a justified start/observation date.
- Building year is a low-confidence age proxy, not a roof installation or condition claim.
- A reported sale or a no-recorded-deed observation is not proven uninterrupted ownership continuity.
- Permit-listed applicant/business, matched business, contractor and verified licensee remain distinct roles.
- BBB absence is unavailable/not observed; it is never converted to a zero rating.

A positive source workflow is accepted only when the source receipts, coverage window and exact joined records support it. [Known limitations](KNOWN_LIMITATIONS.md) states the current limitations; [evaluator guide](EVALUATOR_GUIDE.md) describes how to inspect provenance and unknowns.

Current protected contract `0.5.0` preserves independent municipal permit facts and appends provider-normalized observations. `providerPermitStatus`, `permitActivityClaim` and `minPermitAgeSinceIssueDays` must be satisfied by one observation. An ISSUED-only observation stays activity-not-established; age since issue never becomes continuous open duration. Provider business/party labels and license identifiers remain unverified source observations, with BBB unavailable unless independently acquired.

`minRecordedDeedGapYears` selects only documented current-PIN index observations whose claim window and latest observed deed predate the strict calendar cutoff at that observation's `observedThrough`. A source-wide advertised index start is not a property history window. Current-PIN completeness, verified-through date, retrospective witness qualifications and unreviewed predecessor lineage remain visible. Stronger uninterrupted/legal ownership queries are refused and offer this explicit narrower alternative. Historical public wire artifacts retain their own immutable schema; the producer explicitly validates compatibility before joining the current protected graph.

All protected provider/deed/owner detail text is enclosed by `[data-private-evidence]` and `.private-protected-evidence` capture masks. It does not enter model prompts, logs or trace payloads. Server-rendered citations include the exact observation digest.

The original “open roofing permits older than five years” combines current source-qualified activity with strict calendar age since issue at the admitted provider assessment date `2026-10-28`. For this source date the strict threshold is 1827 days. It does not request uninterrupted five-year work history. Explicit continuous/open-for duration instead requires independently documented native interval evidence. Both retrieval reads enforce the calendar source-date anchor; later caller clocks cannot silently change it. Provider-classified ROOFING candidates with a retained municipal `other` classification are shown with that disagreement, without rewriting municipal facts.

The accepted real age example is City of Novi, Michigan, within five miles (8046.72 meters), `roofMinAgeYears=15`, unknown ages excluded. The unchanged operator is **age greater than 15**, using an explicitly labeled building-year proxy. The accepted 2026-10-29 receipt had 648 matches and 50 returned rows.
