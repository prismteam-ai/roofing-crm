# ADR003: source-specific display and self-contained evaluator access

Status: current policy correction; actual release acceptance remains externally evidenced. Supersedes the categorical public/protected data interpretation in [ADR002](002-engineering-path-and-data-tiers.md), preserving its original record.

Official public property identities and source-permitted observations are product evidence, not secrets. Remove recording masks that hide addresses, parcel/canonical IDs or public owner facts merely because they identify people or property. Keep credentials, genuinely restricted-provider raw material and unrelated private user notes hidden. The [authority matrix](../DATA_FIELD_AUTHORITY_MATRIX.md) separates original requirements, source terms, security and operational choices.

Oracle owns acquisition and field availability. The CRM consumes the versioned observation without inventing names/contacts, re-ingesting sources or treating a postal-only observation as the existing named-owner type. Source dates/joins, low-confidence age basis, native permit semantics and incomplete ownership history stay visible. Null official names or absent phone/email are finite source findings, not intentional global privacy exclusions.

Retain the existing bounded authenticated runtime, workspace-scoped lead state that persists across authenticated sessions and finite shared model quota. The least-change evaluator path is a low-privilege capability directly in the approved PR access section. No initial private email, AWS login or broad authorization redesign is needed. Actual privileged keys/cookies never enter source/media. Draft preparation uses a clear placeholder until the operator resolves its private draft.

A permitted fact's UI/media display is independent of public IPFS publication. Exact-byte Human approval remains required for new bulk owner-containing uploads; provider terms remain source-specific. No paid provider, new source campaign, cloud service or live BBB ingestion follows. No GitHub/video/employer effect occurs before its explicit gate.
