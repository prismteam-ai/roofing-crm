# Security and source-specific data handling

Official public property identities and permitted source facts are evaluator evidence. They may be visible in UI/API/MCP-linked results and the walkthrough. Private S3, authenticated transport and legacy `private_`/`protected-real` names are implementation controls, not a universal confidentiality class. [Field authority](DATA_FIELD_AUTHORITY_MATRIX.md) and [ADR003](adr/003-source-specific-data-and-evaluator-access.md) supersede categorical owner masking.

## Access, sessions and secrets

Keep the existing dedicated low-privilege capability and bounded sessions. The approved PR supplies the capability, live URLs, current limits and recovery instructions directly; a private email exchange or AWS account is not needed for first use. Prepared source/public PR drafts contain an explicit placeholder until the operator resolves the authorized private draft. Sharing the assessment-only capability intentionally does not grant administration, acquisition, publication, outreach or another user's leads.

Signing keys, live cookies/tokens, AWS/API/model/provider keys and connection strings never enter source, logs, media or public artifacts. CRM leads/notes remain mutable own-session records. Authentication, session expiry/replay/isolation and finite quota checks remain security requirements; they do not hide permitted public facts. Never promise that a new session or deployment resets shared counters.

## Rights and publication

Oracle owns source admission and provenance. Preserve null/absent fields; do not invent names or phone/email. Provider restrictions apply to their actual source and raw payload, not unrelated county Open Data. Complete working intake remains retained; raw captures/bulk CAR/Parquet/provider payloads stay outside Git under reference guidance. Exact-byte bulk owner-data IPFS approval is a separate publication gate, not an ingestion/runtime/media ban.

Only query-relevant inputs go to the model; deterministic code owns source facts/citations. Request/response bodies, raw source rows, cookies and raw exception causes remain absent from telemetry. Public property examples are not automatically privacy failures. Scan actual credentials and restricted data, review source-specific findings, and keep OCR/pixel and exact package evidence distinct from code tests.

Temporary-authority retention/cleanup follows the current explicit Human direction. Do not silently revoke retained access or claim credential destruction, whole-home/process-memory/SSO clearance from a payload scan. Existing infrastructure, map origin/action/provider restrictions, bounded notifications and least privilege remain. Local media work does not perform upload, GitHub writes, Ready transition or employer communication.
