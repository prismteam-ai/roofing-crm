# Release checklist

This checklist records required gates; an unchecked gate is not a pass. The final
return supplies observed results and a finite readiness ruling.

- [ ] Reconstruct both bundles/patches into clean temporary clones; verify
      HEAD/tree, lockfiles, runtime and contract/predicate/place digests.
- [ ] Record frozen install controls; run format, lint, typecheck, all unit and
      integration tests, build, exact packaging/emulation, CDK assertions and all
      declared local scripts. Repeat deterministic package hashes where required.
- [ ] Pass the official 63-feature place resolver, at least 80 deterministic
      intents, original exact examples, conflicting/unsupported clauses, no-silent-
      drop mutations and safe refusal before source/model effects.
- [ ] Verify one guarded read, same-permit predicates, source order, minimized
      facts, strict ordinal selection, explicit sort, empty no-model accounting and
      cached fallback without another source read.
- [ ] Reconcile actual source intake/join/unassigned counts, date windows,
      lifecycle semantics, rights, proxy confidence and original-business gaps.
- [ ] Run the bounded deployed model corpus with exact source/package/prompt
      pins, independent references and durable costs; preserve every failed attempt.
- [ ] Verify map/list/detail and GPS allow/deny, pin/radius/filter/reload/mobile,
      real permit evidence, lead retry/version/history/archive/session isolation,
      keyboard basics and disabled future sections.
- [ ] Validate first-use hosted access in fresh profiles and five simultaneous
      actors; assert no stale assets/results, access loops or unexplained 5xx.
- [ ] Compare actual deployed capacity and API controls with approved bounds;
      inspect health/evidence and all loaded frontend hashes against the final package.
- [ ] Review secrets/private data, dependencies/licenses, IAM, headers, sessions,
      publication allowlist and retained-resource/security cleanup. Native review
      unavailable must be replaced only with a disclosed independent fallback.
- [ ] Revalidate historical public artifacts through genuinely independent
      gateway operators. Keep Atlas/publication and IPNS status explicit.
- [ ] Resolve every current documentation link and execute declared commands in
      clean reconstruction. Mark historical P1–P4 instructions superseded.
- [ ] Preserve all 114 original requirements and distinguish code defects,
      source/terms gaps, conditional evidence and artifacts awaiting authorization.
- [ ] Obtain both required review greenlights before any final media work.
      P5 itself does not record/upload media, push code or create PRs.

No source deficiency can be waived by relabeling an original required outcome as
conditional. No green ruling follows merely because retries or time ended.
