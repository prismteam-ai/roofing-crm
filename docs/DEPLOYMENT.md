The bootstrap environment key is `PRISM_BOOTSTRAP_EXECUTION_POLICY_ARNS` (plural). Its value is the comma-separated exact account-specific ARN for `prism-assessment-review-execution-storage`, followed by the ARN for `prism-assessment-review-execution-runtime`. The two managed policies split the task permissions to respect IAM's per-policy size limit. Missing, reordered, additional, legacy singular and AdministratorAccess policies are rejected. The source operator passes each ARN through a repeated standard CDK `--cloudformation-execution-policies` flag, preserving the exact order and individual argument boundaries.
