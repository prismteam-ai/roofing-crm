# Glossary (CRM repository)

Labels used in this repository's commit messages, code comments and docs, with where each is defined. The
pipeline repository's `docs/glossary.md` covers the data labels (increments 1, 2, 4 and 5, run ID, scope guard,
permit-gate exception, slice, join methods, status classes, the reference date).

| Label                                                     | Meaning                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Defined in                                                                                                   |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Test 1 … Test 43, "test 9c", "Hosted test 12", "test 14b" | The numbered tests of the hosted Playwright suite, by the number at the start of each title. Examples: 9c clicks a drawn point about 2 miles from the pin, at the zoom where the 5-mile circle fits, and expects a pin drop, not details; 12 checks parcel details with their source and no owner or contact fields; 14 and 14b check the points cap, and 14c the dashed ring beyond the drawn points; 17 creates, reloads, updates and deletes a lead; 43 checks the leads list's permit-status filter.                                                                                                                                       | `apps/crm/e2e/crm.spec.ts` (test titles)                                                                     |
| Hosted suite                                              | That Playwright suite, run against the deployed site: 51 tests, as 37 and 42 run at four widths each. Its inputs are only `CRM_URL`, `CRM_USER` and `CRM_PASS`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | `apps/crm/e2e/env.ts`, `apps/crm/playwright.config.ts`                                                       |
| Increment 3                                               | The persisted leads: the RoofingCrmLeads stack (table, leads API, shared authorizer) and the lead editor and list in the app.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | `apps/crm/cdk/lib/crm-leads-stack.ts` (file header), `apps/crm/src/App.tsx`                                  |
| Increments 1, 2, 4 and 5                                  | Data deliveries in the pipeline repository: the pilot slice, the data API, the county run, and the City of Los Angeles permits with their contractors and the hosted agent. The CRM reads the run the data API serves: since 17 Nov 2026, `2026-11-17T00-55-12-521Z-b1f1fbb377948`, a rebuild of that day's run `2026-11-17T00-55-12-521Z-bcb7d21c21fe7`, which was new data from a fresh LADBS fetch.                                                                                                                                                                                                                                         | Pipeline `docs/glossary.md`                                                                                  |
| Permits and the agent in the CRM                          | Long-open roofing permits on the map and in a list, permit details with their contractors, the effective roof year, and the "Ask the agent" section.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | `apps/crm/src/PermitsList.tsx`, `apps/crm/src/ParcelPermits.tsx`, `apps/crm/src/AskAgent.tsx`                |
| Effective roof year                                       | The later of the assessor year built and the year of the latest finaled roofing permit; the roof-age threshold counts from it. Its basis is shown: a year-built PROXY or a PERMIT.                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Pipeline `docs/los-angeles-county-findings.md` section 14g; `apps/crm/src/App.tsx` (the rule text)           |
| Long-open                                                 | An issued City of Los Angeles roofing-work permit still open at least the minimum duration (default five years, 1,826 days), with an optional maximum. The "Long-open roofing permits" list counts only those on parcels whose roof is older than the roof-age threshold (a parcel with no roof year never passes it); the agent counts every long-open roofing permit in the radius, so at the same pin and radius its number can be larger.                                                                                                                                                                                                  | Pipeline `docs/glossary.md`; `apps/crm/src/PermitsList.tsx`                                                  |
| Contractor window                                         | Contractor rows exist only for permits issued 2013-01-02 to 2023-05-19; a permit issued outside it shows no contractor.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Pipeline `docs/los-angeles-county-findings.md` section 14h                                                   |
| "Ask the agent"                                           | The aside's section that asks the pipeline's hosted agent a question, centered on the pin. It replaced the disabled agent card; the other placeholder cards stay.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | `apps/crm/src/AskAgent.tsx`                                                                                  |
| Warm-up, held question, re-warm                           | When the section opens it sends `GET /agent/warm` and two data API requests at once; each takes about 0.8 s when warm, so they are in flight together and two data API instances (Lambda execution environments) are warmed. A question asked meanwhile is held ("waking up") until they have answered or 20 seconds have passed. When the warm-up's own last data API response is more than 4 minutes old, the warm-up runs again first.                                                                                                                                                                                                      | `apps/crm/src/warmup.ts`                                                                                     |
| Slice                                                     | The data the API served before the county run: a pilot subset of the LA County roll (one jurisdiction, three ZIP codes). Test 9c's title predates the county run and still uses the word.                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Pipeline `docs/los-angeles-county-findings.md` "Scope of increment 1"                                        |
| Points cap, truncated notice, dashed ring                 | The data API returns at most 25,000 map points, nearest first. When more parcels match, the app says "Map shows the nearest 25,000 of N matching parcels; the count and the list cover all N.", draws a dashed ring at the farthest drawn parcel and says how many matching parcels are not drawn, at or beyond that ring: "N matching parcels not drawn: at or beyond the dashed ring, X.XX mi from the pin." The distance is rounded down, so the parcels left out are never nearer than it says.                                                                                                                                            | `apps/crm/src/App.tsx` (`points-truncated`); `apps/crm/src/beyondRing.ts`                                    |
| Leads in this search                                      | The leads filter for the current radius, roof-age and ownership search. When the map points are capped, leads that are not drawn are checked with the data API's `parcels.match`, in paced chunks of 72 parcel IDs (`MAX_MATCH_IDS`).                                                                                                                                                                                                                                                                                                                                                                                                          | `apps/crm/src/leadsInSearch.ts` (`useLeadsInSearch`, `MATCH_CHUNK`, `Pacer`)                                 |
| "Has a long-open roofing permit"                          | The lead list's toggle, and the map legend's mark: parcels with a long-open roofing permit in the open-duration window of the long-open list, checked with `parcels.match` (`long_open_permit` and the window) or drawn by `parcels.points`. At the Van Nuys test center (34.199, -118.487), 1 mile, 15 years, on the served run `2026-11-17T00-55-12-521Z-b1f1fbb377948`: 112 long-open roofing permits link to 215 parcels, 164 of which have aged roofs; `parcels.match` with the window marks those 164 of the 4,181 aged-roof parcels (4,183 on the 12 Nov rebuild run, which is no longer served; the other figures are the same there). | `apps/crm/src/LeadsList.tsx`; `apps/crm/src/App.tsx` (`points-long-open`, `legend-long-open`)                |
| Ownership filter, basis                                   | "Owner unchanged for 10 years or more": three County-roll proxies the user chooses from, `recording` (no document recorded in 10 years), `base_year` (no reassessment in 10 years, by the land base year) and `both`. Each shows its text and its weakness; none is a sale date.                                                                                                                                                                                                                                                                                                                                                               | `apps/crm/src/ownership.ts`; pipeline `apps/api/src/contract.ts` (`OWNERSHIP_BASIS`, `OWNERSHIP_PROXY_NOTE`) |
| Land base year                                            | The roll's land base year (Prop 13), shown in the parcel details: valid from 1975 to the roll year, otherwise null and shown as "—".                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | `apps/crm/src/ParcelDetail.tsx`; pipeline `docs/los-angeles-county-findings.md` section 15                   |
| Contractor identity                                       | One identity per license number. Each contractor row shows how many name spellings its license carries, when there is more than one; the key (the license number as printed) stays in the page's markup (`data-identity-key`), and the canonical business name is not shown. A row without a license number has no identity. Not verified against CSLB.                                                                                                                                                                                                                                                                                        | `apps/crm/src/ParcelPermits.tsx` (`Contractor`); pipeline `docs/los-angeles-county-findings.md` section 14l  |
| Number fields                                             | The roof-age threshold and the two open-duration fields (in years) are number fields kept as typed: they can be emptied and retyped, show what was typed, and are read when the search runs; an empty or out-of-range value gives a plain message and the search keeps its last valid value. The radius is a slider (0.25 to 10 miles).                                                                                                                                                                                                                                                                                                        | `apps/crm/src/numeric.ts`                                                                                    |
| Leads cap                                                 | The list reads at most 20 pages of 100 leads and says so when more are stored. The 2,000 it reads are the first in the table's scan order, not the newest.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | `apps/crm/src/LeadsList.tsx` (`LEADS_MAX_PAGES`, `LEADS_PAGE_SIZE`)                                          |
| A lead's own permit (`source_permit`)                     | The permit row a lead was created from, set only when it is created from a row of the "Long-open roofing permits" list and never changed. That list holds only Open (issued) permits, so the permit is "Open (issued)" at creation; the other three status choices list only leads whose status read failed, until a later pipeline run records another status for a lead's permit or a lead is written to the leads API directly. A lead created from a map point, a result, a parcel in the agent's Sources or, after a delete, a row of the "Leads" list has none. An "Unmapped status" lead lists only under "all permit statuses".        | `apps/crm/src/App.tsx` (`detailPermit`, `sourcePermit`); `apps/leads-api/src/schema.ts`                      |
| Permit status (lead filter)                               | The leads list's filter on the status class of each lead's own permit. Choices, as the page shows them: "all permit statuses", "Open (issued)", "Open (application stage)", "Closed", "Unclear (neither open nor closed)", "no permit on the lead". The class is read with the data API's `permits.forParcel` while a status is chosen, once per lead for the page's life, at most 4 reads in flight together with the address reads; it is never stored with the lead.                                                                                                                                                                        | `apps/crm/src/leadPermits.ts` (`PERMIT_CHOICES`, `useLeadPermits`); `apps/crm/src/LeadsList.tsx`             |
| "no permit on the lead"                                   | The permit-status choice for leads without a permit of their own (`source_permit`). It does not mean that the parcel has no permit: open a lead to see all its parcel's permits.                                                                                                                                                                                                                                                                                                                                                                                                                                                               | `apps/crm/src/leadPermits.ts` (`passesPermitChoice`)                                                         |
| "status not available"                                    | Shown under a lead's permit number when its status could not be read: the read failed, or the data API's permits for the parcel no longer list that permit. Such a lead stays listed under every status choice. A failed read is not tried again until the page is reloaded.                                                                                                                                                                                                                                                                                                                                                                   | `apps/crm/src/leadPermits.ts` (`PERMIT_STATUS_NOT_AVAILABLE`, `useLeadPermits`)                              |
| Notes rule                                                | The shared check that refuses email addresses, phone numbers with an area code and 7 or more digits in a row in a lead's notes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | `apps/leads-api/src/schema.ts` (`notesProblem`)                                                              |
| LADBS                                                     | The City of Los Angeles's Department of Building and Safety, whose open permit and contractor datasets the pipeline loads.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Pipeline `docs/los-angeles-county-findings.md`                                                               |
| CSLB                                                      | The Contractors State License Board, California's license registry. Not loaded: no license in the CRM is verified against it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | `docs/kit-deviations.md`, rows 19 and 31                                                                     |
| Local lane                                                | The Playwright tests in `apps/crm/e2e/local/` (`*.local.ts`): the built app on 127.0.0.1 with every API answered by page routes, so nothing leaves the machine. The hosted suite does not run them.                                                                                                                                                                                                                                                                                                                                                                                                                                            | `apps/crm/e2e/local/playwright.local.config.ts`; `docs/runbook.md`, section 4                                |
| "hosting plan section 8", "approvals 78.3 and 90.5"       | Used in the message of commit 2033203 (with "revision 2" of the same plan). They name working notes that are not part of the submission.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Commit 2033203                                                                                               |

They were working-note numbers for two decisions: the map key expires on 2027-05-11 (`MAP_KEY_EXPIRES`), and the basic-auth password goes into the CloudFormation template (no Secrets Manager standing cost).                                                                                                                                                                                                                                                                                                              | Commit 4c05106                                                                                               |
