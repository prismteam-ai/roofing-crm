# Glossary (CRM repository)

Labels used in this repository's commit messages, code comments and docs, with where each is defined. The
pipeline repository's `docs/glossary.md` covers the data labels (increments 1, 2 and 4, run ID, scope guard,
permit-gate exception, slice).

| Label                                                     | Meaning                                                                                                                                                                                                                                                                                                                                                                                                | Defined in                                                                   |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| Test 1 … Test 17, "test 9c", "Hosted test 12", "test 14b" | The numbered tests of the hosted Playwright suite, by the number at the start of each title. Examples: 9c clicks a drawn point about 2 miles from the pin, at the zoom where the 5-mile circle fits, and expects a pin drop, not details; 12 checks parcel details with their source and no owner or contact fields; 14 and 14b check the points cap; 17 creates, reloads, updates and deletes a lead. | `apps/crm/e2e/crm.spec.ts` (test titles)                                     |
| Hosted suite                                              | That Playwright suite, run against the deployed site. Its inputs are only `CRM_URL`, `CRM_USER` and `CRM_PASS`.                                                                                                                                                                                                                                                                                        | `apps/crm/e2e/env.ts`, `apps/crm/playwright.config.ts`                       |
| Increment 3                                               | The persisted leads: the RoofingCrmLeads stack (table, leads API, shared authorizer) and the lead editor and list in the app.                                                                                                                                                                                                                                                                          | `apps/crm/cdk/lib/crm-leads-stack.ts:2`, `apps/crm/src/App.tsx`              |
| Increments 1, 2 and 4                                     | Data deliveries in the pipeline repository: the pilot slice, the data API, and the county run. The CRM serves increment 4's county data.                                                                                                                                                                                                                                                               | Pipeline `docs/glossary.md`                                                  |
| Slice                                                     | The data the API served before the county run: a pilot subset of the LA County roll (one jurisdiction, three ZIP codes). Test 9c's title predates the county run and still uses the word.                                                                                                                                                                                                              | Pipeline `docs/los-angeles-county-findings.md` "Scope of increment 1"        |
| Points cap, truncated notice                              | The data API returns at most 25,000 map points, nearest first. When more parcels match, the app says "Map shows the nearest 25,000 of N matching parcels; the count and the list cover all N."                                                                                                                                                                                                         | `apps/crm/src/App.tsx` (`points-truncated`)                                  |
| Leads in this search                                      | The leads filter for the current radius and roof-age search. When the map points are capped, leads that are not drawn are checked with the data API's `parcels.match`, in paced chunks of 80.                                                                                                                                                                                                          | `apps/crm/src/leadsInSearch.ts`                                              |
| Leads cap                                                 | The list reads at most 20 pages of 100 leads and says so when more are stored.                                                                                                                                                                                                                                                                                                                         | `apps/crm/src/LeadsList.tsx`                                                 |
| Notes rule                                                | The shared check that refuses email addresses, phone numbers with an area code and 7 or more digits in a row in a lead's notes.                                                                                                                                                                                                                                                                        | `apps/leads-api/src/schema.ts`                                               |
| D3                                                        | A recorded decision: the basic-auth password goes into the CloudFormation template (`SecretValue.unsafePlainText`), so there is no Secrets Manager standing cost.                                                                                                                                                                                                                                      | Comment in `apps/crm/cdk/lib/crm-web-stack.ts:24`                            |
| D14                                                       | A recorded decision: the map key expires at the end of the account's Free plan (`MAP_KEY_EXPIRES`, 2027-05-11).                                                                                                                                                                                                                                                                                        | Comment in `apps/crm/cdk/lib/crm-map-key-stack.ts:10`                        |
| D2                                                        | Named in the same comment as "the D2 rotation", which would delete the map key before it expires. The repository does not say more about it.                                                                                                                                                                                                                                                           | Comment in `apps/crm/cdk/lib/crm-map-key-stack.ts:10`                        |
| §3b.4                                                     | A reference to the assignment's decision notes, which are not in the repository. The comments that cite it state the rule itself: re-centring the map keeps the current zoom, and test 9c expects the zoom it set.                                                                                                                                                                                     | Comments in `apps/crm/e2e/crm.spec.ts:520`, `apps/crm/test/App.test.tsx:358` |
| Approved change 5                                         | A reference to the same notes. The comment states the rule: the 7-digit rule also refuses a 10-digit parcel ID, on purpose, and the error message says so.                                                                                                                                                                                                                                             | Comment in `apps/leads-api/src/schema.ts:19`                                 |

The D-numbers are numbered design decisions. The repository records only the ones above, in code comments.
Their full list is not part of the repository.
